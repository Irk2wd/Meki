# 第三方许可文本

项目自有源码、文档和资源采用根目录的 [MIT 许可证](../LICENSE)。第三方组件保留各自的许可证，完整声明见 [THIRD_PARTY_NOTICES.txt](../THIRD_PARTY_NOTICES.txt)。

`upstream/` 保存部分组件的许可正文，`overrides.json` 记录对应包版本、来源和文件摘要。原作者的版权姓名及联系信息属于许可正文，按原文保留。

ELK/elkjs 保留 EPL-2.0 条款，其对应源码地址见组件声明。Sharp/libvips 的 LGPL、Lightning CSS 的 MPL，以及其他组件的许可均独立于项目的 MIT 许可证。

Electron 与 Chromium 的许可随运行时分发。Pandoc 和 PicGo 由用户另行安装，Meki 安装器不包含它们。
