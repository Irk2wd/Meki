# 应用内更新

[使用说明](README.md)

## 检查与安装

从帮助菜单或侧栏打开“检查更新”，查看版本说明，再选择下载和重启。启动应用不会自动检查或下载。

重启前需要处理未保存文稿；取消保存会取消更新。多窗口运行时，请先关闭其他编辑窗口。公开版本的更新无需 GitHub 登录。

通常只需下载较小的应用代码包。需要更新运行环境时，软件会下载完整 EXE 或 DMG，再由你运行安装器。macOS 安装时将 Meki 拖入 Applications。

## 下载或更新失败

下载会进行签名和文件校验，未通过校验的文件不会启用。遇到网络错误时可稍后重试，或从 [GitHub Releases](https://github.com/Irk2wd/Meki/releases) 下载完整安装器。

更新包损坏或启动未成功时，下次启动会尝试回到之前可用的版本。更新不会搬动文稿或删除原图，设置、草稿、快照与历史保存在本机。

各版本支持的平台、安装说明和签名状态见发布页面。
