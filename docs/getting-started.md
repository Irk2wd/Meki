# 开始使用 Meki

[文档目录](README.md) · [项目首页](../README.md)

Meki 直接编辑本地 Markdown 文件，适用于 Windows 和 macOS。无需创建账户。

## 获取与安装

从 [GitHub Releases](https://github.com/Irk2wd/Meki/releases) 获取对应平台的文件：

| 平台 | 安装方式 |
| --- | --- |
| Windows x64 | 双击 `Meki-<版本>-Setup-x64.exe`，按向导选择安装目录和用户范围。 |
| macOS Apple Silicon / Intel | 打开 `Meki-<版本>-macOS-universal.dmg`，将 Meki 拖入 Applications，再从“应用程序”启动。 |

签名状态与平台验证范围见对应 Release。卸载应用会保留本地文稿和用户数据。

## 打开第一篇文稿

点击“打开文稿”选择本地 UTF-8 Markdown 文件，也可打开文件夹作为工作区。新建文稿后，首次保存时选择文件名和位置。

在“编辑”与“源码”之间切换，选择适合当前内容的写法。视觉编辑支持表格、任务列表、脚注、目录、提示块和代码高亮；MathJax 公式与 Mermaid 图表可离线渲染。详细语法及转换边界见 [Markdown 兼容性](markdown-compatibility.md)。

未编辑的文件在保存时保留原文、BOM 和换行；视觉编辑会规范化部分 Markdown 写法。

## 整理写作空间

- **分栏与窗口**：将标签拖到编辑区边缘建立分栏，拖动分隔线调整宽度；也可将文稿移入独立窗口。
- **导航与搜索**：通过大纲跳转章节。选中文字后按 `Ctrl+F`（macOS 为 `Cmd+F`）可直接查找；还支持替换与工作区搜索。
- **块操作**：点击文字块左侧的六点手柄打开操作菜单，拖动手柄调整块的位置。
- **外观与语言**：选择主题、字体、字号和正文宽度，或设置正文 CSS。界面支持简体中文和英文，语言更改在重启后生效。
- **专注写作**：按需开启专注模式或打字机模式。

## 保存、快照与恢复

自动保存默认关闭，可从顶部开关或文件菜单开启。外部修改与当前编辑发生冲突时，自动保存会暂停，等待你决定如何处理。

未保存草稿支持恢复；快照可保存当前编辑内容，包括尚未命名的文稿，也可手动命名、预览和恢复。文件版本历史用于查看之前保存的内容。恢复快照或历史后，先检查内容，再保存到文稿。

草稿、快照与历史均保存在本机，重要文稿仍需另行备份。

## 图片与导出

图片可通过粘贴、拖放或选择文件插入，支持尺寸调整和本地附件整理。连接本机 PicGo 后可上传单张或整篇文稿的图片；自动上传默认关闭，原图保留。配置方法见 [PicGo 图床](image-hosting.md)。

HTML、PDF 和 PNG 导出使用与预览共用的正文外观、公式和图表规则。安装 **Pandoc 3.12.1 或更新版本**后，还可导出 Word、EPUB，以及导入 Word、HTML；可在导出对话框中选择本机 Pandoc。Word 和 EPUB 使用各自的排版机制：Word 中常见公式可以继续编辑，复杂公式可能保留为图片；EPUB 中的公式和图表使用图片。

Pandoc 和 PicGo 均需单独安装，不包含在 Meki 中。

## 更新与本地数据

从帮助菜单或侧栏的“检查更新”查看版本说明并下载更新，再自行选择重启。启动应用不会自动检查或下载；运行时升级需要完整安装器。详细流程见 [应用内更新](updates.md#检查与安装)。

设置、恢复数据、快照、文件历史与更新缓存保存在系统应用数据目录。为兼容已有数据，该目录仍名为 `Moye`，与界面显示名 Meki 不同。

应用没有账户、云同步或遥测。检查更新、加载网络图片、打开外部链接、PicGo 上传，以及启用拼写检查后的词典下载会按需联网。
