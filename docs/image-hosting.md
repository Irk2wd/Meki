# PicGo 图床

[使用说明](README.md)

Meki 支持连接本机 PicGo 桌面版，Windows 与 macOS 使用相同的设置。图床账号、插件和云端密钥由 PicGo 管理，Meki 不读取这些配置。

## 连接与上传

1. 在 PicGo 中配置并选定图床，开启 PicGo Server。
2. 打开 Meki 工具栏“图床”或“文件 → 图床设置…”，填写 PicGo 端口，默认 36677。
3. 点击“检测连接”。该操作会保存设置并检查本机服务，不上传测试图片或剪贴板内容。
4. 已保存的文稿可使用“上传文稿图片…”，先预览图片数量、大小与跳过的网络地址，再开始上传。

检测成功只说明本机服务可用，实际上传仍取决于 PicGo 的图床配置。PicGo 的设置方法见 [官方文档](https://docs.picgo.app/gui/guide/advance#picgo-server-usage)。

手动上传支持当前文稿目录或已打开工作区内的本地图片，以及支持格式的内嵌图片。每批最多 32 张不同图片，每张最多 20 MiB，总计 80 MiB。

## 插入时自动上传

“插入图片时自动上传”默认关闭。开启后，只影响随后选择、粘贴或拖入的新图片。

上传失败或取消等待时，会使用本地附件流程；未命名文稿会先询问保存位置，取消保存则不插入图片。

## 单张图片与本地目录

右键图片或点击图片旁的“⋯”，可上传单张本地或内嵌图片，也可复制到指定目录并重命名。网络图片可选择下载到本地，仅在明确执行下载时发起请求。

图床设置中的“本地图片目录”以文稿目录或当前工作区为基准，可使用 `images/${filename}`、`${filename}.assets` 或 `.`。只支持授权目录内的相对路径；工作区模式需先打开包含当前文稿的文件夹。已有图片不会随设置变化自动移动。

## 原图与撤销

上传、下载与复制会更新当前文稿中对应图片的引用，保留尺寸与说明，不修改其他文稿，也不删除原图。撤销会恢复引用，已创建的本地副本仍会保留。

整篇文稿上传后会暂停自动保存，请检查内容并手动保存。失败、部分成功或取消等待时，原引用保持不变；远端可能已上传部分图片，可在 PicGo 或图床中查看。取消等待不能撤回已交给 PicGo 的上传操作。
