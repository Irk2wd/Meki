# mekiR 1.6.2-beta.6

现在可以直接用 Tailscale IP 登录订阅组。mekiR 会向本机的 Tailscale 客户端核对设备名，用它验证服务器证书。订阅保存你填写的 IP，重启后可继续用该地址刷新。

1. 在另一台电脑安装本页的 Windows x64 或 macOS 通用安装包，并连接到订阅服务器所在的 Tailscale 网络。
2. 打开「切换科研项目 → 订阅组」，在「订阅服务器地址」填写服务器的 IP 和订阅端口，例如 `100.70.1.8:9443`。IPv6 地址带端口时写作 `[fd7a:115c:a1e0::1]:9443`。
3. 用只读账号登录，勾选项目，点击「拉取所选项目 → 打开」。登录只读取清单，空订阅组也可以正常打开。

管理后台的组详情和账号详情都可以复制订阅服务器地址。连接失败时，登录框会显示证书、设备身份或网络连接的具体提示。[订阅与部署指南](https://github.com/Irk2wd/Meki/blob/mekir-v1.6.2-beta.6/docs/remote-preview.md)

在本地项目的时间线上，刷新期间点击「新建阶段」或「编辑阶段」，刷新完成后会打开对应表单。

此版本通过本页安装包手动安装，应用内更新继续跟随正式版。
