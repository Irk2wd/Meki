# mekiR 1.5.5

- 同一研究问题可以跨日沿用一篇记录。外部 agent 按项目指引查找已有阶段和记录，把调参、换机位和补基线追加到试次表。时间线按实际实验日期标点，点任意一天都能回到原文。
- 阶段详情分开展示最新结论、结论依据和实验记录。读结论时可以直接对照同一机位的两张图和计时表摘录，点击可打开完整对比或表格。
- 图像对比按原图比例适应窗口。并排查看时可用滚轮或滑块缩放，同一机位的图像同步变化。也可直接选择 100%、200% 或 400% 像素倍率检查细节。
- 在「外观与排版」中可以分别调整应用界面和文档正文的字体、字号。侧栏、菜单、时间线和阶段详情跟随界面设置。
- 当前阶段最近的时间线事件和最新结论图标带有缓慢流动的光边。相邻事件合并时共用一圈光边，开启系统「减少动态效果」后显示静态描边。
