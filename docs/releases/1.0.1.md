# Meki 1.0.1

[使用说明](../README.md)

本次更新统一 Meki 的应用标识、安装包和应用内更新文件命名。

- Windows 程序与文件打开方式统一显示为 Meki。
- 每个平台只提供一套安装包，更新清单直接引用对应的 Meki 文件。
- 应用内更新直接使用公开仓库，无需 GitHub 登录。
- 保留更新签名和文件校验、取消下载、重启前保存文稿及启动失败回退。

Windows 下载 `Meki-1.0.1-Setup-x64.exe` 安装。macOS 下载 `Meki-1.0.1-macOS-universal.dmg`，打开后将 Meki 拖入 Applications，支持 Apple Silicon 与 Intel。

Windows 安装器未进行代码签名，macOS 应用采用 ad-hoc 签名，未进行 Developer ID 公证。首次打开可能出现系统安全提示。
