# mekiR 1.2.0

mekiR 启动后进入上次打开的科研项目。时间线按阶段组织实验和总结，支持最近 7 天、14 天、1 个月和 3 个月，也可自定时段和每页阶段数。

- 从阶段中打开实验和总结，在侧栏阅读或用 Markdown 编辑。沿引用逐篇返回，关闭后恢复原筛选和滚动位置。阶段总结可关联多个项目。
- 给只读证据登记稳定 ID。重新绑定目录后可继续打开原图、计时表及运行清单。重复导入归档按 run ID 更新，预览会列出变化和缺件。
- 组合关键词、时间和字段筛选并保存常用条件。用「复测」「替代」「论文采用」等关系追溯实验、采用依据和稿件版本。
- 每个项目可定义记录类型、字段、模板和视图。Agent 通过 `describe` 读取规则，使用 `batch` 更新记录、`configure` 调整项目。新建项目自带 `AGENTS.md`。

| 平台 | mekiR 安装包 |
| --- | --- |
| Windows x64 | `mekiR-1.2.0-Setup-x64.exe` |
| macOS Apple Silicon / Intel | `mekiR-1.2.0-macOS-universal.dmg` |

mekiR 1.1.4 用户需要先用对应的完整安装包升级。之后可在「帮助 → 检查更新」获取 mekiR 的签名更新。

Windows 安装器未进行代码签名。macOS 应用采用 ad-hoc 签名，尚未进行 Developer ID 公证。
