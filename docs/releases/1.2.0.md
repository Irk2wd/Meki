# Meki 1.2.0

Meki 与 mekiR 从本版起共用一个 GitHub Release。Meki 的应用内更新使用标准版的签名更新清单和安装包。

| 平台 | Meki 安装包 |
| --- | --- |
| Windows x64 | `Meki-1.2.0-Setup-x64.exe` |
| macOS Apple Silicon / Intel | `Meki-1.2.0-macOS-universal.dmg` |

已安装 Meki 的用户可在「帮助 → 检查更新」升级。手动安装时，Windows 运行 EXE，macOS 将 DMG 中的 Meki 拖入 Applications。

Windows 安装器未进行代码签名。macOS 应用采用 ad-hoc 签名，尚未进行 Developer ID 公证。
