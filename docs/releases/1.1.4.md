# mekiR 1.1.4

mekiR 是 Meki 的研究版。它复用原有的 Markdown 编辑器，把实验和总结组织成可浏览、可归档的本地项目。

- 按日期记录实验，为阶段总结指定撰写日期和覆盖区间，从时间线打开记录。
- 项目规则和阶段总结保存在 `.mekir/`。总结可以通过文档 ID 引用项目内的实验、其他总结和普通文档。
- Agent 可通过 CLI 读写记录，并修改项目指引、字段、模板和视图。
- 研究版使用浅色虹彩的 M 图标，右下角带有小 R，有独立的安装包和应用数据目录。

支持 Windows x64 和 macOS Apple Silicon / Intel。[研究项目使用说明](https://github.com/Irk2wd/Meki/blob/mekir-v1.1.4/docs/research-workspace.md) · [Meki 1.1.4](https://github.com/Irk2wd/Meki/releases/tag/v1.1.4)
