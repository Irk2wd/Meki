# mekiR 1.5.0

- 时间线上的阶段共用日期刻度，阶段名下显示最近进展。拖动「项目全程」选区时可在手柄旁看到日期，事件配置和每页条数收在「时间线选项」中。
- 宽屏下可以保留实验列表连续阅读。拖动分隔线可分别调整项目导航、记录列表和预览的宽度，重开后会记住栏宽。关闭预览会恢复原来的筛选和滚动位置。
- 报告可在首段后直接展示引用的对比图。切换机位、拖动分界线即可比较两种结果，打开原图再返回时可接着看同一处。
- CSV 和 TSV 证据支持按行列预览、切换表头和分页。「森林四视角报告」样例附有逐视角计时表、两页 PDF 和三页演示文稿。
- 「外观与排版」提供 8 套字体预设。浏览本机字体时，可组合使用字形分类、「含汉字」和名称搜索。菜单、项目导航与正文会一起换字体。牛皮纸纹理留在阅读区的空白处。
- 修复 macOS 小窗口里对比弹窗与窗口按钮重叠，以及 JSON 等证据预览的关闭按钮点不到的问题。
