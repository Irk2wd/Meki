# mekiR 1.5.1

- 阶段页的「最新进展」显示最近一份总结的结论，可以直接打开报告、引用的对比图和原始证据。项目可指定自己的结论字段，也可以在 Markdown 总结末尾写「结论」。
- 从项目侧栏切换阶段时，可以接着读上次打开的记录。向下滚过正文标题后，顶栏会显示报告名，便于连续阅读。
- 图片、CSV、TSV 和 JSON 可在报告旁预览。点「固定到右栏」保留要对照的证据，再打开其他文件会复用临时标签。切回已固定的计时表时会保留页码。
- 点击记录中的字段或正文顶栏的「字段口径」，可以对照数值写入时的定义、单位和当前项目规则。Agent 也可读取这两版定义。旧记录缺少历史依据时会标明「写入时的定义未留存」。
- 文稿编辑器同步了 Meki 的标签分隔线和分栏选中样式。
