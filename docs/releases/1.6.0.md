# mekiR 1.6.0

- 在「搜索项目」中选择「智能检索」，可以直接询问某个实验结论是否在复测中成立。回答会标出引用的实验记录、试次或资料页，点击引用即可查看原文。
- 项目可把实验表中的数值列关联到原始 CSV 或 TSV 的列、筛选条件和统计方法。核对后的数值可以点击，直接定位到参与计算的原始数据行。
- 每个项目可选用已登录的 Codex CLI，或配置 OpenAI、DeepSeek 等模型服务。设置里可选择快速、标准、深入或自定义检索深度。智能检索默认覆盖本项目的研究记录和已登记资料，提交前会提示问题及相关片段将发送给所选模型。
- 外部 agent 可以用 `smart-config` 配置模型和深度，用 `smart-search` 获取带引用的结论、对比表及仍待补充的证据。
- 项目资料筛选、模型设置和基础编辑器的下拉菜单采用一致的布局，支持键盘选择。
