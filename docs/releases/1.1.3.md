# Meki 1.1.3

这次更新让文稿定位更方便，也让多文稿编辑时的标签栏更整齐、稳定。

## 更方便地找到文稿文件

- 文稿标签、顶部文件名和最近文稿列表新增位置右键菜单，可在 Finder 或资源管理器中显示文件，并复制完整路径。
- 右键后台文稿时，操作准确对应所选文件，当前编辑内容和未保存状态保持不变。
- 尚未保存的文稿和已被移走的文件会给出清楚的提示。

## 更稳定的标签栏

- 长文件名自动省略，关闭按钮保持固定大小并居中显示。
- 切换文稿或缩窄窗口后，当前标签与关闭按钮会一起保持可见，避免被右侧操作区遮挡。
- 标签过多时支持鼠标滚轮横向浏览；分栏标签独立滚动，收起分栏按钮固定在右侧。
- 改善未保存标记、深色主题和界面缩放下的对齐与间距。
