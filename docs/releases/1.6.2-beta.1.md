# mekiR 1.6.2-beta.1

这版可以在另一台电脑只读查看研究项目。发布电脑把项目快照推送到 WebDAV，订阅电脑可以查看时间线、研究阶段、最近结论和可视化对比。需要分享某篇实验记录的全文时，可以在发布设置里把它加入精选。

1. 在开展实验的电脑上，打开「项目设置 → 发布远程预览」，填写 WebDAV 项目目录和发布账号，选择「保存并发布」。启用自动发布后，mekiR 运行期间也会发布外部 agent 写入的进展。
2. 在另一台电脑安装本次 Beta，从项目切换器选择「订阅远程项目」，填写同一目录和只读账号。首次拉取完成后，即使发布电脑已关机，也可以从服务器查看最近一次快照。已读项目离线时可以打开本地缓存。

服务器迁移时，复制项目目录并在两端更新地址，即可继续使用原订阅。[远程项目预览指南](https://github.com/Irk2wd/Meki/blob/mekir-v1.6.2-beta.1/docs/remote-preview.md)

本次为手动安装的测试版。应用内更新继续跟随正式版。
