# mekiR 1.2.1

- 新建或编辑阶段时可留空结束日期。已开始的阶段按项目时区延伸到今天，填入实际结束日期后于次日显示已结束。[Issue #1](https://github.com/Irk2wd/Meki/issues/1)
- 进行中的阶段置顶，已结束的阶段按结束日期倒序。补写总结时，历史阶段保留顺序。[Issue #2](https://github.com/Irk2wd/Meki/issues/2)
- 可在阶段内保存原图对比网格和 Markdown 图注。同一行同步缩放与平移，支持 1:1 原像素并可打开只读证据。Agent 可通过 CLI 读取或写入展示记录。[Issue #3](https://github.com/Irk2wd/Meki/issues/3)

| 平台 | mekiR 安装包 |
| --- | --- |
| Windows x64 | `mekiR-1.2.1-Setup-x64.exe` |
| macOS Apple Silicon / Intel | `mekiR-1.2.1-macOS-universal.dmg` |

已安装 mekiR 1.2.0 的用户可在「帮助 → 检查更新」升级。更早的 mekiR 1.1.4 用户可直接使用本版完整安装包。
