# mekiR 1.6.2-beta.4

这个 Beta 支持用一个只读账号浏览已加入的订阅组，按项目选择要下载的快照。在另一台电脑上打开项目后，可以沿用本地项目的操作方式查看时间线、阶段总结、已分享的实验记录和可视化对比。

1. 安装本页的 Windows x64 或 macOS 通用安装包，打开「切换科研项目 → 订阅组」。
2. 填写管理员提供的**订阅服务器根地址**和只读账号。登录时只读取组和项目清单。
3. 勾选要查看的项目，点击「拉取所选项目」。出现「已拉取」后点「打开」，即可进入只读工作区。已下载的快照和缩略图可以离线阅读。

同一个项目出现在多个组时，本机共用一份副本。移除正在查看的副本时，工作区会返回本地项目。以后仍可从组里重新拉取。已有单项目订阅的设备可以使用已保存的账号连接订阅组，沿用匹配项目的缓存。

管理员可以通过独立网页维护组成员、项目和发布权限。读者刷新清单即可看到变更。[订阅与部署指南](https://github.com/Irk2wd/Meki/blob/mekir-v1.6.2-beta.4/docs/remote-preview.md)

本次为手动安装的预发布版。应用内更新继续跟随正式版。
