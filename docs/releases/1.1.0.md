# Meki 1.1.0

这次更新，让写作更安心，整理内容更顺手。自动版本历史会记下文稿的变化，新的拖拽体验让长文调整更轻松，更新提醒也能在不打断写作的情况下及时送达。

## 自动留住写作过程

右上角的「版本历史」现在会自动记录发生变化的文稿，包括尚未命名的草稿。按日期浏览记录，先预览内容，再决定是否恢复，找回删掉的一段话或修改前的表达更方便。

近期修改保留得更细，较早的记录会自动整理，兼顾内容找回与存储空间。后台草稿保护也更轻量，多篇文稿同时编辑时，可以减少反复写入带来的负担。

## 更顺手的内容拖拽

拖动段落、列表等内容块时，可以直接看到内容预览和清晰的插入位置。加号、拖拽手柄与插入线采用更自然的渐变过渡，靠近长文边缘时会自动滚动，跨段落整理内容更连贯。

按住 **Alt / Option** 拖动可复制内容，按 **Esc** 可取消本次拖动。

## 更新提醒，安静送达

启动后和使用过程中，Meki 会定期检查适用于当前平台的新版本。发现更新时显示轻量提醒，点击即可阅读发布说明，再自行选择下载和安装。

后台检查不会自动下载或安装；也可以在更新窗口关闭自动提醒，继续使用手动检查。

## 更清爽的界面与 macOS 体验

- 侧栏新增「设置」入口，外观、文稿保存、快捷键和图片相关设置更容易找到。
- 全新的字标与应用图标，搭配更均衡的顶部留白，让写作空间更简洁。
- macOS 上的行内公式编辑恢复正常，点击公式即可继续修改内容。
- 改善状态栏文字的对齐与间距，常用信息更清楚。

## 下载与升级

- **Windows x64**：下载 `Meki-1.1.0-Setup-x64.exe`，按安装向导升级。
- **macOS**：下载 `Meki-1.1.0-macOS-universal.dmg`，打开后将 Meki 拖入 Applications，同时支持 Apple Silicon 与 Intel。

升级会沿用已有的设置、草稿、会话和历史记录。推荐使用完整安装包升级，以一并更新系统中的应用图标。

Windows 安装器未进行代码签名；macOS 应用采用 ad-hoc 签名，尚未进行 Developer ID 公证。首次打开可能需要系统确认。
