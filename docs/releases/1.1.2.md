# Meki 1.1.2

这次更新修复应用内更新后图标仍停留在旧版的问题，并新增正文与标题级别快捷键。

## 图标随版本更新

macOS 运行中的 Dock 图标会同步为当前版本的图标。新版应用图标与安装时不同时，应用内更新会选择完整安装器，让安装目录中的图标也能更新；图标未变时仍使用轻量更新。

旧版更新器尚不支持图标检查，因此首次升级到 1.1.2 需要完整安装器。macOS 打开 DMG 后，将 Meki 拖入 Applications 替换原有应用，再重新启动。

## 快速切换正文与标题

在即时预览和源码模式下，按 `Ctrl+0` 切换为正文，`Ctrl+1`～`Ctrl+6` 切换为对应级别标题；macOS 使用 `Cmd`。

这些按键可在「设置 → 自定义快捷键」中修改或清除。「实际大小」的缩放快捷键改为 `Ctrl+Shift+0`（macOS 为 `Cmd+Shift+0`）。

## 下载与升级

- **Windows x64**：下载 `Meki-1.1.2-Setup-x64.exe`，按安装向导升级。
- **macOS**：下载 `Meki-1.1.2-macOS-universal.dmg`，将 Meki 拖入 Applications，支持 Apple Silicon 与 Intel。

升级会保留已有设置、草稿、会话和版本历史。

Windows 安装器未进行代码签名；macOS 应用采用 ad-hoc 签名，尚未进行 Developer ID 公证。首次打开可能需要系统确认。
