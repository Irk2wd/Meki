# mekiR 1.5.3

- 选中研究阶段后，先看到这个阶段要回答的问题和最近一次有证据支持的结论。实验列表也在标题下显示一句结论。新报告若只有待验证事项，上一条已确认的进展会继续显示。
- 项目指引和实验模板引导外部 agent 按研究问题复用阶段。调参、换机位和补基线可以分别归档到同一阶段。运行 `describe` 可读到已有阶段的研究问题、最近总结和实验。
- 实验和阶段总结先写实测结果、比较条件和证据，推测与待补对照集中在文末「待验证」。项目可以指定自己的结论字段。
- 收起项目侧栏后，可通过图标切换时间线、实验记录和阶段总结。文稿编辑器也支持图标侧栏，窄窗口会自动为正文腾出空间。
