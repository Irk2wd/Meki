# Meki 1.1.1

给宽表格和长代码多一点空间。这次更新带来更舒展的编辑区，也为需要充分利用大屏幕的文稿提供了可选的无宽度上限布局。

## 更舒展，也有分寸

默认正文宽度上限提高到 **1040px**，并新增 **1200px** 档位。大屏幕下居中显示、保留留白；缩窄窗口或调整分栏时，内容和留白会随可用空间收缩，左侧的加号和拖拽手柄仍有完整的操作空间。

已保存的正文宽度偏好会继续沿用，可在「设置 → 外观与排版 → 正文宽度」选择新档位。

## 为特殊文稿放开宽度

在「设置 → 外观与排版 → 高级布局」中，可开启 **取消正文宽度上限**，让表格和代码使用当前窗口的可用宽度，同时保留左右留白。

这个选项默认关闭，开启后会记住设置并同步到其他窗口。关闭即可恢复原来的正文宽度。它同时适用于即时预览和源码编辑，导出文件的宽度仍按原有排版设置处理。

## 下载与升级

- **Windows x64**：下载 `Meki-1.1.1-Setup-x64.exe`，按安装向导升级。
- **macOS**：下载 `Meki-1.1.1-macOS-universal.dmg`，将 Meki 拖入 Applications，支持 Apple Silicon 与 Intel。

也可通过应用内更新获取新版本。升级会保留已有设置、草稿、会话和版本历史。

Windows 安装器未进行代码签名；macOS 应用采用 ad-hoc 签名，尚未进行 Developer ID 公证。首次打开可能需要系统确认。
