# Meki 1.0.0

Meki 是面向 Windows 和 macOS 的本地 Markdown 编辑器，项目自有代码、文档和资源采用 MIT 许可证。

- 即时预览与源码编辑，支持表格、任务列表、脚注、目录、提示块和代码语法高亮。
- 随应用提供离线 MathJax 公式与 Mermaid 图表，预览和导出共用排版规则。
- 多标签、独立窗口、拖动分栏和大纲导航；支持选词查找、替换与匹配定位。
- 自动保存、草稿恢复、文稿快照和本地版本历史。
- 简体中文与英文界面，三套主题及受限正文 CSS；支持输入习惯、快捷键和代码块设置。
- 本地图片粘贴、拖放、尺寸调整与附件整理，可连接本机 PicGo 上传。
- HTML、PDF、PNG 导出；安装 Pandoc 后可导出 Word 与 EPUB。
- 手动检查签名更新、下载后重启及代码包回退。

Windows 使用 `Meki-1.0.0-Setup-x64.exe` 安装，macOS 使用 `Meki-1.0.0-macOS-universal.dmg`，打开后将 Meki 拖入 Applications。各平台是否提供安装包及验证范围，以该 Release 的实际资产和验证记录为准。

升级沿用原应用数据目录，保留设置、草稿、快照和会话。轻量更新不会替换已安装的系统宿主或重命名旧快捷方式；需要统一系统显示名时使用完整 Meki 安装器。第三方组件保留各自许可证，见随包组件声明。
